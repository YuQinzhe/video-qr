- v1.mp4
- v2.mp4
- v3.mp4
- v4.mp4
- v5.mp4
- v6.mp4

请确保文件名与上面完全一致，建议全部小写。

## 推荐上传方式

因为 v1 和 v4 约 39.44 MB，不建议使用 GitHub 网页的普通上传界面。
推荐使用 GitHub Desktop：

1. GitHub 新建 Public 仓库：`video-qr`
2. 在 GitHub Desktop 中 Clone 该仓库
3. 把本项目所有文件复制进本地仓库文件夹
4. 把 6 个 MP4 放进 `video/`
5. GitHub Desktop 中 Commit to main
6. Push origin

## 开启 GitHub Pages

Settings → Pages → Build and deployment  
Source: Deploy from a branch  
Branch: main  
Folder: / (root)  
Save
